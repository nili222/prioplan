# PrioPlan

Eine einfache Organisations-App für Schule, Arbeit und Privat. Sie kombiniert Aufgabenliste und Kalender und speichert die Aufgaben direkt im Browser.

## Lokal starten

```bash
npm install
npm run dev
```

## Online veröffentlichen

Jeder Push auf den `main`-Branch baut die Website automatisch und veröffentlicht sie über GitHub Pages.
